# L13.1 · Heap, GC, dan AOT cache

**Hari 5 · berpasangan · 25 menit · slide 122 (pola di slide 117–121)**
**Checkpoint:** `L12-perf` (lihat [mode-perf.md](mode-perf.md))

## Tujuan

Mengatur heap relatif terhadap memory limit container dan mengukur dampaknya; membandingkan startup JDK 25 tanpa vs
dengan AOT cache. Satu variabel per pengukuran.

## Langkah

### 1. Heap default di container 1 GiB

```powershell
docker run --rm -m 1g eclipse-temurin:21-jdk java -XX:+PrintFlagsFinal -version | Select-String ' MaxHeapSize'
docker exec tokoku-order-service-1 sh -c "java -XX:+PrintFlagsFinal -version | grep ' MaxHeapSize'"
```

Berapa MaxHeapSize? Berapa persen dari limit?

### 2. `MaxRAMPercentage` + NMT

Di `infra/compose.yaml`, untuk **order-service** saja:

```yaml
    environment:
      <<: *app-env
      JAVA_TOOL_OPTIONS: "-XX:MaxRAMPercentage=70 -XX:+ExitOnOutOfMemoryError -XX:NativeMemoryTracking=summary"
```

Restart (`docker compose ... up -d order-service`), jalankan beban L12.1 (b), lalu:

```powershell
docker exec tokoku-order-service-1 jcmd 1 VM.native_memory summary
```

Catat: heap efektif, **total committed** NMT, dan sisa ruang terhadap limit 1 GiB (thread stack, metaspace,
code cache, GC, direct buffer).

### 3. Opsional: G1 vs generational ZGC

Tambahkan `-XX:+UseZGC -XX:+ZGenerational` (JDK 21) **tanpa mengubah heap**, beban yang sama, bandingkan p99 dan CPU.

### 4. AOT cache (JDK 25)

```powershell
.\scripts\aot-cache.ps1 -Runs 3
```

Skrip membangun product-service di JDK 25, melakukan training run (`-XX:AOTCacheOutput` +
`-Dspring.context.exit=onRefresh`), lalu mengukur startup 3× tanpa dan 3× dengan `-XX:AOTCache`.

- [ ] Tabel heap efektif dan NMT terisi.

## Jebakan umum

- Mengganti GC **dan** heap sekaligus dalam satu pengukuran: perubahan tidak bisa diatribusikan.
- `-Xmx` = memory limit container: non-heap tidak punya ruang → OOMKilled (D13.2).
- AOT cache hanya berlaku untuk JVM dan classpath yang identik (jar yang di-extract, versi JDK sama).

**Tips Windows:** `grep` hanya ada di dalam container; di PowerShell pakai `Select-String`.
