# L19.1 · Test suite order-service

**Hari 4 · individu · 35 menit · slide 102 (pola di slide 96–101)**
**Checkpoint:** `L19.1-start` → `L19.1-solution`
**Infra:** Docker Desktop menyala (Testcontainers). Compose tidak wajib kecuali untuk `OrderServiceApplicationTests`.

## Tujuan

Menyusun portofolio test sesuai pyramid: banyak unit test cepat, slice test di batas teknologi, dan jalur gagal
downstream (timeout + fallback).

## Yang sudah disediakan

- Dependency test: starter `-test` per teknologi (Boot 4), Testcontainers 2, **WireMock** 3.13.
- Kerangka empat class test dengan daftar TODO:

  | Class | Jenis | Package |
  |---|---|---|
  | `PlaceOrderServiceTest` | unit (MockitoExtension) | `application.service` |
  | `OrderControllerTest` | `@WebMvcTest` | `infrastructure.adapters.in.rest` |
  | `OrderRepositoryTest` | `@DataJpaTest` + PostgreSQL Testcontainers | `infrastructure.adapters.out.persistence` |
  | `InventoryTimeoutTest` | WireMock + context minimal (sudah disiapkan) | `infrastructure.adapters.out.http` |

- Data uji `src/test/resources/seed/orders.sql`.
- Image `postgres:17-alpine` dan `apache/kafka:4.2.2` sudah ditarik lewat `prepull.ps1`.

## Langkah

1. **Unit test** `PlaceOrderService` dengan `@ExtendWith(MockitoExtension.class)`: tiga kasus stok
   (AVAILABLE, INSUFFICIENT, UNKNOWN).
2. **`@WebMvcTest(OrderController.class)`**: 401, 403, 404 Problem Details, 400 Problem Details.
3. **`@DataJpaTest`** + `@AutoConfigureTestDatabase(replace = NONE)` + `@Container @ServiceConnection
   PostgreSQLContainer`: query hanya mengembalikan order milik customer itu (slide 100).
4. **WireMock delay 6 s**: `InventoryClient` timeout sekitar 5 s; breaker OPEN → `UNKNOWN` tanpa memanggil inventory.

Jalankan `.\mvnw.cmd -pl order-service test`, **dan juga** dari test runner IDE.

      VS Code: panel Testing).

## Jebakan umum

- **`@WebMvcTest` sejak L11.1 menghasilkan 401, bukan 404/400.** Controller order terlindungi:
  butuh `@Import(SecurityConfig.class)`, `@MockitoBean JwtDecoder`, dan `.with(jwt().jwt(t -> t.subject(...))
  .authorities(() -> "SCOPE_orders.read"))` (pola slide 99).
- `@SpringBootTest` untuk semua hal: suite lambat dan rapuh.
- Lupa `read-timeout` eksplisit di properti test: nilai produksi hasil L10.1 (500 ms) membuat skenario
  "delay 6 s → timeout 5 s" tidak bermakna.
- Meng-inject class `InventoryStockAdapter` langsung: karena `@Retryable`, bean-nya berupa proxy. Inject port
  `StockCheck`.
- `@MockBean` sudah tidak ada di Boot 4: pakai `@MockitoBean`.
